# 本走メモ作成 / Run Memo Builder

テイルズ オブ ベルセリア リマスター(Steam)RTA 用の、トレジャーポイント拾得計画(本走メモ)を作るページです。
NewGame までの操作(または n0)と、素材の目標確保数を入れると、拾う地点の表・宝箱の回収計画・予測されるランダムスキルを出します。
計算はすべてブラウザの中で行います(サーバーへの送信はありません)。PNG で保存して、オーバーレイ表示などに使えます。

A page for Tales of Berseria Remastered (Steam) speedruns that builds a treasure point pickup plan ("run memo").
Enter your actions before NewGame (or n0) and your target material counts to get the list of points to pick up, the chest plan, and the predicted random skills.
Everything runs in your browser. Use the English checkbox at the top right to switch languages.

- ページ / Page: `index.html`(1ファイルで動きます / single self-contained file)
- 前提のルート: 2026-10-10 の本走テスト(NewGame〜ロウライネ) / Route: the 2026-10-10 test run (NewGame to Lothringen)
- 英語版のゲーム用語(装備・スキル・地名・リザルトのセリフ)はゲームの英語テキストから取っています。見た目の説明などは日本語からの訳です。
  Game terms in the English version (items, skills, locations, result lines) come from the game's English text; place descriptions are translations from Japanese.

非公式のファンツールです。Unofficial fan-made tool; not affiliated with Bandai Namco Entertainment.
